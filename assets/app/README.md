# Last Singularity App Assets

Generated v0.2 placeholder app assets live here.

- `icon.svg` is the editable source icon.
- `icon-256.png` and `icon-512.png` are generated from `npm run assets:app`.
- Desktop and Steam Deck installers copy `icon-512.png` as `last-singularity-icon.png` beside the Linux executable so `.desktop` files and Steam shortcuts can reference a normal filesystem path.

These are shippable placeholders, not the final wordmark or store art.
