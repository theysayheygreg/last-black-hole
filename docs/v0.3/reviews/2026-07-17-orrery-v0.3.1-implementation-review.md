# Orrery Implementation Review — v0.3.1 Candidate (2026-07-17)

> Target: `codex/v0.3-ballpark-roadmap` @ 6603c3ad. Method: four parallel
> verification lanes — completion-MD audit (all 23, 33 suites re-run),
> Wave-1 spine vs S4/S5/S8 specs, Conductor/encounters vs S12/S15/S9,
> and product-truth from captures + the real Deck session. Everything
> below was verified against code with anchors; executing agents' full

## Verdict

**The swarm delivered the design.** The authoritative spine is real:
one movement truth (2.5 stick-relative, shared step module, 1e-12
trajectory parity), one gravity family, seeded sea under the ambient
floor with determinism guards, cap-relative slingshot with the exact
5-knob contract, ruler layer + force ledger, live-rebuilt coarse field,
the Conductor with five primitives, total pressure-meter deletion
(test-enforced), per-entity growth with attribution, banded epochs,
canonical 5×5/15×15/25×25. Completion MDs were honest — every
re-runnable claim reproduced, including the 28.13% slingshot margin
byte-for-byte. The game has a coherent session shape for the first
time, and X-D's numbers validate the pacing math (cruise ≈ 1.4 s/cell
on every map; Deep Field crosses in ~25 s; the 30-second rule fits).

**Two things keep it from the taste gate:** a crash bracketing the
payoff moment, and a systematic pattern — **the solo path lags the
authority**. The designed game exists in remote-authority play; solo
still runs meaningful pieces of the legacy game. Greg's feel verdicts
happen in solo. That is S5's "verdicts against the non-shipping game"
trap, rebuilt one layer up.

stated plainly: **solo feel-tuning currently tunes the wrong game.**
Either solo adopts the authority path (local server, as packaged builds
already do) or the fallback is labeled dev-only and the taste gate runs
remote-authority exclusively.

   snapshot-rehydration class as the star crash that WAS fixed

   duration or short fixtures die forever.

   regression proofs don't gate commits — which is how finding 4 hid.

   `vector.magnitude`; sim snapshots carry only `{x,y}` — magnitude is
   added in presentation normalization). The only live proof of the
   ruler layer cannot pass as written.

   extraction → Home → second launch — is the missing receipt for the
   entire retention loop.
