# v0.3.1 Velocity Ledger — Full Force Inventory

> Companion to `v0.3.1-design-review.md` S5. Research pass 2026-07-14 on
> `codex/v0.4-multiplayer-architecture`. Raw accounting of every code path
> that writes object velocity in the authoritative sim, with normalized
> magnitudes. Anchors may drift with commits — grep the named constant.

World units: map is `worldScale` wu across (Shallows 3.0, Expanse 5.0, Deep
Field 10.0). Sim tick dt = `timeScale/tickHz` (15/12/10 Hz per profile).
Player movement consumes the shared session dt; no player-specific clock multiplier exists.

**≈12.6 → always cap**; pulse ≤0.5; recoil 0.4; scav bump 0.3; eject 0.3;

the dominant term, gravity ≈ one Drifter-thrust; escape is the intended
coupling/thrust fight. Waves: mid-weight on Shallows, noise on big maps.
Slingshot release: outlier, effectively set-speed-to-cap.

## D. Map/profile scaling

Force constants identical across maps. What differs: `useCoarseField`
(Expanse/Deep sample grid, smooths peaks), `fieldFlowScale` 0.22/0.28
multiplies wave push on coarse maps only (`:4981`) → **waves ~4× weaker off
Shallows**, tickHz 15/12/10 changes per-tick decays (§E), well masses are
map-authored ×(0.85–1.15) seed.

## E. dt bugs

1. **Wave amplitude decay per-tick** (`*= 0.97`, `:2859`): half-life 1.5 s
   Shallows / 2.3 s Deep Field / **0.38 s client** (per-60fps-frame,
   `src/config.js:160`). Three wave lifetimes for one constant.
2. Fauna drag ×0.99/tick (`:5761`) — tickHz-dependent.
3. Swarm drain probability per tick (`:6085`) — distribution shifts with Hz.
4. `runSystemAtRate` drops accumulated time past 2 catch-ups (`:4294-4301`)
   — world systems time-dilate under load relative to player physics.
