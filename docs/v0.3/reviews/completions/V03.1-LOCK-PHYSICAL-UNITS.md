## Canonical Schema

`src/content/units.data.json` is the sole shared code-data authority. Its
versioned `inputs` contain only the irreducible physical values:

| Input | Value |
|---|---:|
| `metersPerSimUnit` | `1000` |
| `drifterHullLengthMeters` | `12` |
| `rulerPresentationDefaultMeters` | `100` |

The `ratification` block records `status=locked`, owner `Greg`, date
`2026-07-17`, and the decision source. The manifest intentionally does not
store `drifterHullLengthSimUnits`; browser and CommonJS wrappers derive it as
`12 / 1000 = 0.012` and expose byte-equivalent raw inputs.

## Consumers And Residue

  `INTERNAL.unitScaleMeters`, stored sim hull literal, old status field, and

- Compatibility residue is limited to `UNIT_SCALE.scaleBarMeters` and
  `UNIT_SCALE.status/source` aliases for existing callers. They are derived
  wrapper properties, not additional data authority.
