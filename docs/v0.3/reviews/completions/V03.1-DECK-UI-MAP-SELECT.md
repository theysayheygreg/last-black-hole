# v0.3.1 Deck UI and Map Select Lane A

## Outcome

Source and focused presentation pass complete on
`codex/v0.3.1-deck-ui-map-select`. This lane owns UI/layout, Map Select, the
controller-visible packaged title exit, and directly coupled proof/docs only.
Gameplay authority, package release, broad CI, merge, push, and physical Deck
acceptance remain outside the lane.

## Shipped

- The title screen pairs the select command with a shared `B EXIT` glyph rail.
  Controller back reaches the Electron main-process quit bridge; `app.quit()`
  retains normal embedded-server cleanup for SteamOS.
- Shared Deck tokens now define the 1280x800 geometry contract: 22/18 panel
  insets, 16px panel gaps, 40px headings, 240x56 command slabs, 58px rows,
  44px icons, 132x52 value blocks, and 32px action glyphs. Footer prompts have
  a local backing and distinct labels instead of a disconnected glyph cluster.
- Ship/loadout, Vault, Home tabs, inventory rows, and Map Select consume the
  shared footprints. Text values fit their content column rather than running
  into the right panel edge.
- Map Select's center is now a seeded, deterministic broad-field survey with
  irregular contour traces, density, interference, open void, and uncertainty.
  It does not expose exact entities, routes, spawns, or portals.
- The right rail uses possible contents and canonical aggregate ranges. Scale,
  risk, topology tuning, overview copy, and visible content descriptions resolve
  from each map's canonical registry descriptor rather than a UI-owned table.
  Locked rows use redacted corruption treatment rather than telemetry-looking
  red bars.
- In-match wreck labels pick separated slots and receive a presentation-only
  local matte.

## Taste call

The center survey is intentionally interpretive rather than a miniature map:
its contours communicate scale and topology while preserving uncertainty. The
right rail chooses text ranges and descriptions over meters because the source
truth is aggregate, not a player-readable progress value.
