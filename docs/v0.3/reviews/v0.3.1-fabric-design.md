## The Finding: Three Seas

- **A. GPU fluid (the fabric you see).** 15+ injection sources. Nothing
  gameplay ever reads it back — `FlowField.sample()` (`src/ship.js:236`)
  is fully analytic; the only GPU readback feeds a debug overlay
  (`src/main.js:6067`). Every splat is cosmetic, solo and MP alike.
- **B. Client analytic FlowField** (`src/sim/flow-field.js`) — drives solo
  gameplay: well currents + rings + star hazard.
- **C. Server flow** (`estimateFlowSample` / coarse field) — drives MP:
  well current only in direct mode; +gravity/waves baked (stale) in coarse.

Contradictions the player can see: GPU well stirring paints **infall**
while the authoritative current is **pure tangential**; client coarse
baseline is a third formula (0.7 radial + 0.3 tangential) matching neither;
surf normalization differs 3.5× between client and server; coarse-mode wave
terms are frozen at field build (`rebuildAuthoritativeField` only at init/
profile change, `sim-runtime.cjs:1679/:1322`).

## The v2 Architecture: One Flow Truth, Two Resolutions

Authoritative flow field v2 (Ballpark-side, coarse):

1. **Well terms** — orbital current + gravity (existing, one formula family).
2. **Seeded sea** — swell trains generated from map procgen history (the
   residue of past collapses), the G2 ambient floor. Replaces client
   random ambient turbulence as the source of "the fabric is alive."
3. **Live event waves** — existing ring events, dt-correct decay, uniform
   weight (G3), tracked live in coarse mode (fix staleness).
4. **Collapse retune** — sea state parameters shift as wells consume mass
   (Wave Race tide-per-lap analog; feeds Wells/collapse pass).

Presentation: the GPU fluid is **forced by the authoritative field** each
tick (inject coarse velocities as forcing terms); advection/vorticity may
add sub-floor visual detail that never exceeds ambient magnitude. Screen =
f(authority + bounded noise). Enforcement: nothing on screen may promise a
force the authority won't deliver.

Skill rule (from Wave Race): **ship-velocity angle vs wave front** is the
one interaction — parallel = carried, perpendicular = cost/plunge, across =
line drift. All wave feel tuning hangs off this single rule.

## Test (fabric v2)

- Screenshot pair: GPU fabric motion field vs authoritative field sampled
  at the same points — direction agreement within tolerance everywhere
  above the ambient floor.
- Wave-riding agent beats wave-ignoring agent by target margin using the
  angle rule only.
- Two procgen seeds → visibly different spawn seas; same seed → same sea.
- Kill the GPU sim entirely (debug flag): gameplay outcomes unchanged.
  That test proving true is the definition of "one sea."
