# Last Singularity Theme Glossary

> Canonical language for the v0.3 candidate. This is shared vocabulary, not a lore expansion.

## Product and route

| Term | Canonical meaning | Use |
|---|---|---|
| **Last Singularity** | The player-facing product name. | Always use this name; `last-black-hole` is repository history only. |
| **route** | A player-readable path through the current run. | A route is suggested by world facts, never guaranteed. |
| **aperture** | The cyan portal interaction zone used for extraction. | Entering it exposes the interaction; it does not extract by itself. |
| **residence** | Remaining inside an aperture long enough for the authoritative interaction state to be true. | Never call this a charge unless a charge mechanic exists. |
| **confirm** | The explicit Enter/A action that requests extraction while the player remains in an aperture. | The server decides whether confirmation succeeds. |
| **abort** | The immediate loss of aperture readiness after leaving it. | It is a state change, not a failure penalty. |
| **extracted** | The authoritative successful run outcome. | Prefer this over victory, win, or escape when reporting an outcome. |
| **collapsed** | A run ended by universe collapse. | Preserve this result label. |
| **residue** | The authored survival credit after a non-extracted run. | Not loot, a refund, or a percentage tax. |
| **echo** | A durable trace left by a prior run, including an echo wreck or Chronicle fragment. | Evidence, not a promise of recovery. |

## Color roles

| Word | Meaning | Do not use for |
|---|---|---|
| **cyan** | Route, aperture, extraction. | General “good” status or salvage. |
| **amber** | Salvage, value, ledger credit. | Route guidance or danger. |
| **red** | Immediate consequence, damage, terminal warning. | Ordinary emphasis. |
| **magenta** | Inhibitor, corruption, anomaly. | Generic rarity or UI decoration. |
| **gold** | Not a semantic color word in player-facing copy. | Use *amber* for value/salvage. Raw source-art pixel descriptions are the sole exception. |

## Entity families

| Term | Meaning |
|---|---|
| **fauna** | Non-sentry ecological life in the run. |
| **sentry** | A watchful hostile/defensive entity family; not fauna in copy. |
| **scavenger** | A rival salvage actor. Do not imply human intelligence or a full combat contract it does not have. |
| **Inhibitor** | The run’s consequence presence. Capitalize the proper name. |
| **glitch / swarm / vessel** | The named Inhibitor forms after dormant. Use only when the authoritative form is known. |
| **well** | A gravity hazard and route-shaping anchor. Do not call every well a black hole. |
| **wreck** | Drifting salvage evidence and terrain; never a loot box. |

## Career and instrument terms

| Term | Meaning |
|---|---|
| **Chronicle** | The compact career strip and newest five authoritative run records. |
| **career** | Durable profile history, not a rank ladder. |
| **ledger** | The authoritative record of credited EM and outcomes. |
| **manifest** | The current listed cargo, not a promise that it will survive the run. |
| **telemetry** | Instrument-style reporting of known state. Use for terse status language. |
| **cycle** | A completed run interval when no stronger outcome word is available. |

## Roster boundary

**Drifter** and **Breacher** are the only public hull names. Resonant, Shroud, and Hauler remain internal definitions; do not put them in player-facing UI, public copy, or route text.
