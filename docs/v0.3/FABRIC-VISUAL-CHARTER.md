# Fabric Visual Charter — ratified Q&A

> Recorded by Orrery from Greg's answers, 2026-08-04. This supersedes any
> prior "match the concepts" framing, including Orrery's
> orbit-with-coherence three-part recommendation from the same evening.
> Status: design intent for the tuning phase; not a work order.

## The ranking (wins every tradeoff)

**Telegraphy > Navigation > Mood.** Quiet baseline so events own the
screen when they happen; routes readable second; beauty in service of
both. Horror pacing.

## Ratified intents

1. **Currents are continuous routes** (the OG design, from the
   game-name days): a current runs across distances as one traceable
   route, with varying strength along its length. Direction is readable
   from the shader against calmer space. The shader also expresses
   intensity by source — wave, well, ambient (faster / slower / more
   gravitic). Inhibitor visuals override where applicable.
2. **Gravitic starts at the body.** The well's own silhouette/corona
   carries the gravity read for now (fabric stays honest current-only).
   Architecture must allow warp, flow-acceleration, or both to be added
   *independently* later — matching the simplification staging: player
   can see and use the fabric for gameplay first; complexity and
   authored treatments come later for larger bespoke maps.
3. **Honesty core, art-directed surface.** Mechanical truth (visible
   intensity ∝ real carry) is the underpinning contract, but the
   presentation gets artistic license — license exists to make the true
   signal *perceivable*, never to contradict it. Until the affordance
   is clear enough, strict honesty alone "means nothing."
4. **Inhibitor fabric treatment is its own future pass** (non-blocking).
   Minimum mechanism when it comes: a z-layered VFX element with render
   preference over fabric, and/or shader-level substitution of glitched
   ASCII characters for normal ones — possibly both.

## Deliberately open (do not enshrine)

- **Calm-density ratio**: the recent marked-vs-void ruler was
  short-term scaffolding for the simplification pass, not a project
  rule. Multiple bugs/overlaps were found while using it. Tune by eye.
- **Calm motion (aliveness at rest)**: to be revisited wholesale
  between OG v0.2 energy and current beta restraint — but **not before
  movement clarity is proven**. Intelligibility tests deliberately took
  precedence; the dial comes back up later.

## Concept images

The three 2026-08-02 img-gen frames (noise-storm rivers, ribbon arcs,
well-lens) are **mood reference only**. Nothing measures against them:
no acceptance comparisons, no "match the concept" language in any spec.
Physics note kept on record: the fluid pipeline is divergence-free —
flow around wells is orbital; convergence/inflow is not achievable and
acceptance language must never require it.
