Read order

01 / Flow and route

ASCII fabric is the movement medium. Broad world-anchored lanes, 4–5 visible hull widths, use broken downstream marks for direction and strength.

02 / Actionable category

Player, threat, wreck, anchor, portal, fauna, and anomaly separate by silhouette before hue or labels.

03 / State

One persistent accent plus one brief source-bound event cue. No permanent halo/ring/trail/label/sparkle stack.

04 / Dread and detail

Void owns at least half the perceived frame. Detail arrives only after route and category survive.

Rendered world specimen

Target grammar: void → sparse fabric corridors → dark landmark body → contained pixel entities → brief VFX. This is a guide diagram, not gameplay evidence.

Sprites and shader/material rules

World sprites use hand-authored pixel sheets/cards or pixel-textured top-down meshes: nearest-filtered, aspect-correct, and snapped to stable pixel multiples where practical. The shader/material layer keeps fabric sovereign: lanes derive from accepted current, well darkness and aperture black are analytical reads, and the accumulated density buffer is additive-only—never negative splats or entity-shaped clearing holes.

Substantive amendments require Greg ratification; renderer objects consume published presentation facts and never invent authority.

Separation stack

1 / Contact matte

Hard local patch below core; normally ≤1.25× silhouette. Reduce low-priority cluster coverage before core value.

2 / Core + rim

Pixel-resolved category silhouette and thin edge. Use nearest filtering; preserve aspect ratio and stable pixel multiples.

3 / Halo + trail + accent

Energy/state/motion only. Pooled and settled from published state. Never substitutes for a readable core.
