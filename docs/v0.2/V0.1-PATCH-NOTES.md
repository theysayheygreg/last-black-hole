# v0.1 Historical Patch Notes

v0.1 is the entire playable-prototype era before the v0.2 product foundation. It starts with the jam concept of **Last Black Hole** and ends with the game renamed and structurally pointed at **Last Singularity**.

## Headline

Built a browser/WebGL extraction roguelike where the primary skill is reading a collapsing ASCII fluid universe, stealing salvage, and deciding when to leave before signal, gravity, rivals, and the Inhibitor make the run unrecoverable.

## Core Game

- Added a playable top-down ship with mouse/keyboard controls, inertia, thrust, brake, drag, current coupling, gravity pull, and wraparound world navigation.
- Built the first run loop: title/home, map select, launch, loot wrecks, survive hazards, extract through portals, die or escape, and return to a result/profile flow.
- Added three map scales: Shallows `3x3`, Expanse `5x5`, and Deep Field `10x10`.
- Added named gravity wells, stars, comets/planetoids, wrecks, portals, wave rings, and fixed-grid fluid windows.
- Added cargo pickup, dropped loot, wreck aging, value scaling, and cargo loss on death.
- Added profile slots, pilot naming, vault/sell behavior, run records, and chronicle foundations.

## Movement And Feel

- Established "Movement Is the Game" as the central practical design rule.
- Replaced the early free-thrust assumption with a delta-v economy: thrust costs fuel, brake is reverse thrust, coasting matters, and current-reading saves resources.
- Added hull-specific movement coefficients through PlayerBrain and shared hull content manifests.
- Added the slingshot anchor network: wells, stars, and planetoids can be engaged as deliberate movement rails with energy banking and chain windows.
- Added first-pass hull movement identity: Drifter rides currents, Breacher forces lines, Resonant chains more forgivingly, Shroud moves quietly, Hauler pays mass costs for cargo reach.

## World Pressure

- Added well growth and consumption, portal waves and expiry, wreck drift toward wells, and stellar remnants.
- Added signal zones and a signal HUD.
- Added Inhibitor pressure, forms, HUD degradation, and run-ending dread state.
- Added client-side phantoms and pre-spawn hauntings as "the universe noticed you" texture.
- Added fauna/sentry snapshot/rendering foundations, with the full ecosystem still needing playtest and content tuning.

## Rivals And Interaction

- Added scavenger/rival behavior, cargo competition, portal use, death consequences, and remote-player rendering.
- Added force pulse as the primary non-lethal interaction verb.
- Added consumables including fuel refill, shield burst, time slow, and breach flare.
- Added server-side hull ability state and several active/passive ability behaviors: flow lock, eddy brake, burn, resonance tap, frequency shift, wake cloak, decoy flare, salvage lock, and tractor field.

## Progression And Content

- Added five hull classes: Drifter, Breacher, Resonant, Shroud, and Hauler.
- Added rig track definitions, profile upgrade shape, and PlayerBrain resolution.
- Added JSON content manifests for hulls, items, signatures, session profiles, and balance.
- Added tiered artifact catalog with coefficients, hull affinities, special ids, and consumable catalog.
- Added cosmic signatures and seeded-generation foundations.

## Renderer And Presentation

- Established the ASCII-over-fluid identity as product, not polish.
- Built the raw WebGL2 fluid simulation and Composer post pipeline.
- Added `FluidDisplayPass`, bloom, gain, accretion, tonemap, color grade, vignette, ASCII, chromatic aberration, and scanline passes.
- Added directional ASCII character ramps that respond to velocity.
- Added DOM HUD, inventory panel, signal meter, warnings, ability presentation, run results, and profile/home screens.
- Added a parallel Three renderer path, then promoted it toward first-class top-down 3D while preserving the flat viewpoint.

## Runtime And Architecture

- Split the game from an in-browser-only prototype into a local multi-process product shape: dev server, control plane, authoritative sim, and browser/Electron renderer.
- Added the local HTTP sim protocol: join, input, inventory action, snapshot, events, session start, and leave.
- Moved major run truth server-side: player transforms, map state, portals, extraction, cargo, inventory mutation, hazards, scavenger consequences, rival players, slingshot authority, and run write-back.
- Added control-plane profile/session ownership, session registry, host promotion, live-session join semantics, structured runtime telemetry, and stack launcher/status commands.
- Added map-scale session profiles, relevance gates, per-player force caps, overload states, and coarse authoritative field sampling for larger worlds.

## Test, Build, And Tooling

- Rebuilt the test harness around manifest lanes: `fast`, `core`, `static`, `browser`, `authority`, `visual`, `playtest`, `three`, and `full`.
- Replaced Puppeteer dependency with a smaller Chrome DevTools Protocol driver.
- Added renderer fixtures and screenshot capture for visual regression review.
- Added authoritative remote tests covering movement, delta-v, slingshot, pulse, inventory, hazards, death, join, leave, and host promotion.
- Added web and desktop build scripts, Electron packaging, static build metadata, and versioned build folders.

## Known v0.1 Limits

- The design docs outgrew the live game and often described future systems as if they were current.
- The main design bible still assumed free thrust, raw WebGL/Pixi as the renderer question, and incomplete progression.
- Maps were designed before slingshot became a central route verb.
- Meta-loop, rig purchasing, missions, milestones, and persistence write-back were only partially productized.
- UI and HUD presentation remained split across DOM, canvas overlay, and renderer code.
- Multiplayer was architecturally real for local/private authority, but not a public hosted product.
